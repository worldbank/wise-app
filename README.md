# `{wiseapp}`

## Overview

`{wiseapp}` is a Shiny application for estimating how weather affects welfare,
simulating weather and climate scenarios, and evaluating adaptation policies.

See the [User guide](https://datanalytics.worldbank.org/wise-app-docs) for full
documentation. The data preparation workflow is available in the
[wise-app-data repository](https://github.com/worldbank/wise-app-data).

## Installation

Install the development version from GitHub with `pak`:

```r
pak::pkg_install("worldbank/wise-app")
```

## Run

Launch the application with:

```r
wiseapp::run_app()
```
